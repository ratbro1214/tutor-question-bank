# 二次函数参数专题研习（2026-10-27）

## 本轮范围

入口 `/topic-lab`，侧栏“数学专题研习”。新增一个不依赖模型调用的教学流程试点，复用已有标准式核验器。包含端点与严格性、全称与存在、顶点与区间、次数退化四类、共16道研发自编题。

每次选择一题作为原题，按“首次作答 → 诊断追问 → 教师讲解 → 新题检查 → 间隔复查”记录。后续检查必须与原始作答显式关联、围绕同一观察重点，且使用本次未做过的另一题。教师手动判断正确性与完成方式；固定规则提示下一步，不自动归因、不输出掌握率。

“实际课堂观察”要求复查至少在新题检查24小时后记录，这是试点的流程约束，不代表已验证的最佳复习间隔。“教学演练”可当次走完，导出明确标识用途；不生成模拟学生作答，也不等同于智能体实验。

## 演示步骤

1. 保留“教学演练”，选 E1。记录示例答案“a<0，因为题目是严格不等式”，教师判断错误。
2. 诊断选 E2，追问 x=0 是否在定义域、a=0 是否可行。按观察填写，不用预先认定错因。
3. 讲解回到 E1，比较 E1 与 E2 的边界可达性，记录实际讲解。
4. 新题检查选 E3，记录是否独立得到 a≤2；提示后正确不能当作独立正确证据。
5. 演练复查选 E4，独立正确的参数范围应为 a<−1。两次正确只描述这两次记录。
6. 导出 JSON 后可在空白专题页导入，程序重新核验记录顺序、题目、关联和时间。

页面内存暂存，刷新或跳转前必须导出；没有自动保存到数据库，也没有关联真实学生档案。导出只包含已加入时间线的内容，不包含编辑框中未提交的文字。无需数据库迁移，不修改已有业务记录。工具链接只负责导航，不会自动传递专题数据。

## 题集与评测

执行 `node node_modules/tsx/dist/cli.mjs scripts/prepare-quadratic-topic.ts`，在外层 `outputs/quadratic-topic/` 生成 `development-pack.json` 和 `教师核对材料.md`。核对材料含计算参考，不能交给盲评标注者。

继续执行现有 `evaluate-methods.ts --pack ../outputs/quadratic-topic/development-pack.json`，得到冻结题包、三组离线预测、盲评题目和标注模板。全部16题留在开发集，同一观察重点按组保留；没有独立标签时不计算准确率。

现有核验器只计算教师录入的标准式。本题集的标准式由研发者编写，未独立审核。自动测试中的期望参数范围是研发者的手工数学回归预期，不是独立评测标签。题集需要教师独立审阅，并另收集有来源、无同源泄漏的测试题。
