# AI 智能备课：阶段 5A-1

本轮仅实现基础工作台及手动持久化闭环。入口 `/lesson-plans`，沿用根目录 `Start-Tutor.cmd` 启动与 5173 端口。页面需要现有 ChatGPT 登录；本地使用原有安全的单用户模拟登录中间件。

## 操作

1. 在“AI 智能备课”创建新教案，填写专题；默认高中、高三、45 分钟、一对一家教。目标和教师手填的基础水平可稍后补充。
2. 桌面端左侧选择知识点、输入关键词，调用既有 Canonical 题库；添加例题时先读取真实详情中的当前内容版本。窄屏点击“教学资源”展开。
3. 中间手动填写教学目标、知识分析、教学流程、例题讲解、课堂练习、课堂总结及逐题备注；点击保存。没有自动推断学生状态，也不调用 AI。
4. 刷新或从历史列表继续编辑，恢复数据库中的内容和固定版本题干。历史版本可载入为草稿，再保存成新版本；不会改写历史记录。
5. 列表支持学段、专题、归档筛选；复制生成独立草稿。归档可恢复为草稿，没有永久删除接口。
6. 保存失败后保留当前页面草稿，可以重试。建议离开前下载“草稿恢复文件”，下次导入并保存。JSON 是恢复工具，数据库仍为已保存教案的唯一来源，不用 localStorage 充当数据库。
7. 409 冲突不覆盖服务器内容：新标签页查看服务器版本；下载草稿后重新载入，或“草稿另存为副本”。更改草稿后生成新提交编号；同一失败请求原样重试沿用编号。

## 数据设计

`lesson_plans` 保存所有者、专题/学段投影、状态、整数修订号、当前版本 UUID、当前 JSON、创建/更新时间。状态为 draft / ready（教师已确认）/ archived。所有者来自服务器登录信息，不能从请求提交。每次读写按 owner_id 限定。

`lesson_plan_versions` 为每次保存的不可覆写快照，记录完整 JSON、状态和时间。唯一 `(plan_id, revision)`；id 同时作为幂等提交 UUID。当前版本指针由同一个 D1 batch 维护，没有引入循环外键；不开放直接改写版本的 API。

`lesson_plan_questions` 为每个快照的有序引用；`(canonical_id, revision_id)` 复合外键指向同一道 Canonical 的具体内容版本，RESTRICT 删除。版本和位置、版本和题目身份分别唯一。存用途及教师备注，不复制另一套题库；题干从原版本加载，来源和题图继续沿用现有题库路由。上游题图生命周期并未因此获得永久保留保证。

没有提前建立教案环节、AI 运行和导出任务表。5A-1 的六个编辑区是明确字段的文本，`flow` 暂为教师手写流程；5A-3 再扩展结构化环节和 AI 运行状态。当前助手明确标为未接入，不伪造 pending/success 任务。对内容使用 `schemaVersion: 1`，后续需要显式升级转换。

保存采用 `expectedRevision` 条件更新、操作 UUID 及 D1 事务 batch；版本和题目引用仅在成功的提交指针下插入。任一 SQL 失败整体回滚；失败的并发写不留下快照或题目记录。引用保存及读取都校验实际内容版本和可访问 scope。

## API

| 方法与路径 | 行为 |
| --- | --- |
| GET `/api/lesson-plans?stage=&topic=&status=active` | 仅当前所有者列表；status 支持 active、archived、all |
| POST `/api/lesson-plans` | 创建；提交 id、operationId、expectedRevision=0、status、content；复制也调用此接口 |
| GET `/api/lesson-plans/:id` | 读取当前教案、版本目录及固定版本资源 |
| GET `/api/lesson-plans/:id?version=:uuid` | 读取所属历史快照作为草稿；返回当前修订号用于下一次条件保存 |
| PUT `/api/lesson-plans/:id` | 条件保存、确认、归档、恢复；提交 operationId、expectedRevision、status、content |
| GET `/api/math-library`、`/:id`、`/:id/image/:occurrence` | 复用既有题库检索、详情及私有原图读取，无修改 |

JSON 内容结构：

```json
{
  "schemaVersion": 1,
  "topic": "教学专题",
  "stage": "高中",
  "grade": "高三",
  "duration": 45,
  "scenario": "一对一家教",
  "goals": "",
  "baseline": "",
  "analysis": "",
  "flow": "",
  "examples": "",
  "exercises": "",
  "summary": "",
  "questions": [
    { "canonicalId": "真实身份UUID", "revisionId": "该题真实版本UUID", "purpose": "讲解", "notes": "" }
  ]
}
```

此处 UUID 文本是结构说明，实际 API 必须是合法且存在的 UUID。专题上限 160 字、每个内容区 20000 字、题目上限 30、时长 1～480 分钟、请求上限 512000 字节。未知字段、无效 JSON、重复身份和跨题版本拒绝。HTTP 401 未登录、404 不存在/其他所有者、400 无效输入/引用、409 冲突、500 数据库异常。跨站写入拒绝，私人响应 no-store。
