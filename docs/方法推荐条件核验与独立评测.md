# 方法推荐条件核验与独立评测

日期：2026-10-19。

## 页面使用

在 `/math-methods` 的“解题策略建议”或“题目智能推荐与一题多解对比”中，展开“两个专题的标准式条件核验”。

1. 将题目等价整理为一种支持的标准式，填写系数、有限区间、端点开闭及相关题干的逐字引用。
2. 参数标准式为 `a ≤ / < / ≥ / > g(x)`，其中 `g(x)=u*x²+v*x+w`，可以选择全称或存在量词。系数为零时分别按一次或常函数处理。
3. 基本不等式标准式为 `p*x+q/x`，要求 p、q 为正，区间左端点严格大于零。计算等号点 `sqrt(q/p)`，再比较区间端点与内部驻点。
4. 确认转写与原题等价，再生成建议。表单修改会取消旧请求并使结果失效，需重新分析。

例：`x∈(2,5)` 时 `x+1/x` 的通用下界是 2，但等号点 x=1 不在定义域；实际下确界为 2.5 且取不到，因此没有最小值。若改为 `[2,5]`，最小值才是 2.5。

例：`∀x∈(0,2), a<x²` 得 `a≤0`；若包含 x=0，则变为 `a<0`。严格不等式的参数端点不能一律删除。存在量词按逐点可行集合的并集处理，不能套用全称结论。

## 核验边界

- 这是受限标准式的解析公式与数值计算，不是通用符号证明器。没有从自由文本自动识别所有公式，也不验证原题到标准式的等价变形。
- 只支持非空、非单点、有限区间；不支持参数出现在 g 的系数中、无穷区间、一般多元约束、一般不等式及几何证明。超范围保留人工核验，不使用采样冒充证明。
- 系数、端点限制在 ±1,000,000；过窄区间或过近但不相同的候选值会拒绝数值判定。输出是浮点结果，不替代精确数学书写。
- 原题含不可读字符、题干引用不匹配或未确认转写时不计算；不因提交引用就宣称转写已被机器证明。
- 标准式与教师量词、方向、正性、等号可达性冲突，或所求参数最值不存在时，规则首选降级。候选方法卡不会自动变为已审核。
- AI 引用失配时清空解题步骤；倒数等号不可达时，相关直接取等首选降级。核验通过也不会自动认定 AI 解法正确。
- 不新增数据库表，不修改学生记录，不自动写入题目—方法关系。

## 冻结与盲评流程

运行 `npm run evaluate:methods`，默认读取 `data/method-evaluation/development-v1.json`。产物保存在项目外层工作目录 `outputs/method-evaluation/<时间>/`：

- `frozen-pack.json`：解析并冻结的题包，`predictions.json` 记录其 SHA-256。
- `predictions.json`：检索、规则、规则加条件核验三种预测，以及核心方法快照哈希、执行源文件哈希和可选评分。
- `blind-review-cases.json`：仅包含题目、来源、分组和划分，不包含系统建议或教师输入的规则事实。
- `labels-template.json`：待填写标注模板，未填写不能评分。
- `method-key-reference.json`：方法键、名称及适用条件，帮助教师统一标注。
- `报告.md`：标注状态和解释边界。

默认8题都是研发自编样例，没有独立教师标签，也没有测试集；不会生成准确率。真正独立评测须另准备题包：

1. 由教师提供有来源、无学生个人信息的题目，建议第一轮40—60题。按母题／变式家族设置 group，同组不能跨 development/test；保留数学符号检查重复题干。
2. 题包不存答案标签。facts 与 verification 是教师提供的辅助输入，因此该评测是“教师辅助条件下的推荐”，不是端到端自动读题精度。
3. 用 `npm run evaluate:methods -- --pack <题包路径>` 冻结题包并导出。冻结测试集后不得依据测试结果持续调参；研发样例不可简单改为 test 后声称独立。
4. 将盲评题目和方法键说明交给未参与开发的教师；不要提供 predictions.json。填写 acceptableKeys（可接受方法）、forbiddenPreferredKeys（不可作为首选的方法）、理由、reviewerId，可选标注参数边界和开闭或等号可达性。允许可接受方法为空，不能强行选方法。
5. 标注人员与开发者身份不同并声明独立时，报告才标为“标注者声明独立”。程序不能认证人员身份；争议题应先由另一教师复核再冻结标签。建议记录双方判断和最终裁定的外部审阅记录。
6. 用 `npm run evaluate:methods -- --pack <同一冻结题包路径> --labels <标注路径>` 评分；哈希不一致、同源泄漏、未知方法、重复标签、无效预测会被拒绝。产物保留使用的标签及哈希。

## 指标解释

各引擎分别报告开发集与测试集：标注覆盖率、Hit@3、Recall@3、错误首选比例、首选覆盖率、弃权比例、标准式核验准确率。Hit@3 计算存在可接受方法的标注题中，前三项至少命中一种的比例；Recall@3 汇总这些题的前三项命中方法数／全部可接受方法数。错误首选比例以全部已标注题为分母，必须结合首选覆盖率阅读，不能把全部弃权的零错误解释为高能力。无样本的比率为 null。

核验准确率对有核验标签的题目比较状态，以及可选的参数边界／开闭、等号可达性；边界数值比较采用 1e-9 相对尺度容差。它不评价一般解题证明，也不等于推荐准确率。

当前三组都是离线、零模型调用；未执行“直接AI / 检索AI / 检索与核验AI”的真实模型消融对比，也没有教学收益实验。下一轮在固定模型、提示词及成本记录后另做模型对比；真实学生收益还需前后测和新题独立作答证据。

离线评测使用23张核心策略的虚拟已审核快照，仅用于公平比较算法；不读取或批准业务数据库中的候选卡。
