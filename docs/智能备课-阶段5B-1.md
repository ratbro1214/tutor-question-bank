原 5A 的 `lessonContentSchema` 同时约束结构非空、正时长、精确总时长与引用。5B-1 保留它用于 AI 输出、教师确认和导出，增加 `lessonDraftSchema` 允许结构文本/数组未完成、暂时零分钟与总时长不一致。保存服务仍核验重复选题、环节引用、例题身份和 revision、scope；不是放松题库身份。负数/非数字时间不进入持久化，编辑中的本地规则可提示它们。

数据库继续使用 `lesson_plans`、`lesson_plan_versions`、`lesson_plan_questions`，不持久化临时报告及问题处理状态。

## 使用

在原 `/lesson-plans/:id` 的 AI 助手区打开“教案质量检查”。窄屏通过“AI 助手与历史”显示该区。

1. **快速检查**：立即显示本地规则结果，再读取服务端题库权威状态；不调用模型。
2. **AI 深度检查**：教师主动触发，结合规则结果和当前草稿。输入、打开、保存不会自动调用。
3. 点击**定位编辑区**跳转并聚焦手写文本、环节或题目引用区。结构化整体建议定位到结构区，不能精确定位的建议定位到整体编辑区。
4. 可标记待处理、已处理（教师标记）、忽略。状态仅影响当前报告，不修改教案，也不是正确性认证。
5. 对可安全修复的问题点击**生成修改建议**，查看原文与建议。接受前内容不变；接受仅生成未保存草稿，并保留备份。拒绝只移除建议。
6. **保存教案**沿用 CAS/幂等/历史。内容或保存 revision 变化后，旧报告提示过期、旧建议禁用，重新检查后建立新关联。

## 规则与可信度

规则涵盖结构化环节总时长、无效时间和明显集中分配提示；未选择/重复/错误 revision 的结构引用；目标、重难点、流程、空关键环节、例题讲解安排、练习和总结完整性；题库答案 reviewed/unverified/missing，以及未读取权威状态时的无法确定。

普通数字、题号和相似文字不用于确定正文引用错误。当前页面观察到移除或替换选题时，增加“核对旧题正文”的建议；既有编辑器仍主动清理失效结构引用。重新打开页面后不会凭空推断过去替换事件，旧正文需主动 AI 或教师核对。

时间求和仅针对实际结构化 `stages.minutes`。手写流程不做不可靠的自然语言分钟解析。单环节占时较多是可优化建议，不能作为确定错误。

题库审核状态取自 `LessonStore.aiQuestions`，不信任教案内可变的 answerStatus。知识点仅在固定版本 payload 有明确 human_review 证据时标为 knowledgeReviewed；仅 `needs_review=false` 不等同于人工审核，没有明确证据则降为依据不足。

AI 输出经 schema 校验，最多 20 条，不能输出 error/certain；数学问题强制冠以“疑似数学问题，需教师核对”，并注明未完成数学正确性验证。引用证据必须匹配相应输入区块，证据或位置不成立时降为整体建议/依据不足。没有图像像素，不宣称核验图形、完整题目条件或标准答案。

## API 与安全边界

新增 `POST /api/lesson-plans/:id/quality`，四种 mode：rules、ai、repair、accept。沿用登录/所有者、跨站限制、512 KB 请求上限、no-store，以及 scope/固定 revision 校验。输入必须含 expectedRevision 和当前 content；repair/accept 还核对当前内容的精确 JSON 快照。所有者检查在处理报告前完成。

报告包含问题 ID/source/severity/category/title/description/location/evidence/suggestedAction/confidence/status，以及快照、revision、checkedAt、elapsedMs、aiRequests。快照采用完整规范内容字符串，避免短哈希碰撞；属于临时页面数据，不写公共日志或数据库。

局部修复仅允许手写 goals/analysis/flow/examples/exercises/summary 或指定环节 explanation。time/reference/answer 类、整体/结构化整体或不明确位置只支持手动核对。不能改环节题目 ID、revision、题库审核状态或其他环节。接受时再次请求服务端核对 revision/引用；接受请求不写库，最终保存依然使用 CAS，接受期间页面变化也会拒绝覆盖。

模型每次显式操作最多一次请求，不隐藏重试；失败后教师可主动重试。复用 provider timeout/取消及响应读取器。输入删除备份、导出设置和学生提要，保留教学文本、结构、所选题和必要的审核依据；超 180 KB 不盲目截断上下文，返回精简提示。网络中断导致收不到服务统计时，前端明确注明请求次数无法确定。
