# 英语历年真题与阅读精练数据库

当前已整理 2020–2025 年新高考英语Ⅰ、Ⅱ卷共 12 套。阅读精练包含 48 篇阅读 A–D、12 篇七选五、240 道题、1140 条选项，以及 240 条按来源题号对应的答案。听力不进入练习或结构化阅读表。原件可能包含其他题型。

## 页面与答案状态

打开 http://127.0.0.1:5173/english ，默认进入“阅读精练”。可切换年份、卷别、阅读 A–D 或七选五；选择选项后逐题或整篇对照来源答案，查看答案原件，也可重新练习。作答和学习进度仅保存在本次页面会话中。

答案状态为 SOURCE_ALIGNED，表示只完成题号与来源答案的映射，不表示已验证答案正确性。verified_at 为空，本次没有晋级 VERIFIED 的答案。不同来源有重新编号：例如 2020Ⅱ卷答案中的阅读编号 16–35 对应题卷 21–40；部分答案把阅读编号改为 1–20，映射时加 20。2020Ⅰ卷、2024Ⅱ卷和 2025Ⅱ卷采用所收录题卷的 1–20 阅读编号。证据记录保留 sourceNumber、questionNumber、rawAnswer 和具体偏移方法。

## 来源与提取

主要原件来自中国教育在线分页公开页面，2024Ⅰ卷补充高考直通车公开 PDF。每份原件保存来源页面、下载 URL、SHA-256、采集时间、大小和本地副本。最终清单共 357 个原件及网页快照，位于 data/english/manifest.json；采集指导仅作为参考文档，不作为执行外部操作的授权。

调用 MinerU skill，在 E:\AI\MinerU 的本地环境解析。Office 使用其 flash 格式解析，图片与 PDF 使用 standard OCR；没有上传至远程解析服务。完整 PDF 指定 --pages all。OCR 输出写入 E:\codex\毕设探索\work，程序直接处理这些文本，避免把整卷和图片重复送进对话。

程序按大节、篇目、题号和选项拆分；只检查结构和对应关系，不推理或交叉验证答案。data/english/extraction-corrections.json 记录少量原图转录修正（例如 OCR 把选项 A 识别为题号）。2025Ⅰ卷 A 篇图表通过 MinerU 图像块导出，插入文章对应位置；保留块定位。细小装饰图片不进入阅读正文。

## 数据库设计

沿用项目 SQLite / Cloudflare D1 与 Drizzle，新表独立于学生、错题和原有套卷表。

| 表 | 用途 |
|---|---|
| english_papers | 年份、卷别、标题；年份+卷别唯一；READING_READY 表示阅读已可练习 |
| english_artifacts | 来源原件、SHA-256 和预览路径，关联试卷 |
| english_sections | 阅读、语言运用、写作分节 |
| english_passages | 阅读正文、篇目标记、来源定位；EXTRACTED 表示已提取 |
| english_questions | 题号、题型、题干、分值，关联篇目 |
| english_options | 每题选项；题目+选项标签唯一 |
| english_answer_evidence | 来源答案、原始题号、对应题号、映射方式，关联原件 |
| english_answers | 答案、状态、证据 ID 和独立复核时间 |
| english_annotations | 可重算附属数据；本次用于 reading-figures 图表定位与预览路径 |

关系：试卷→分节→文章→题目→选项；题目→答案与来源证据；文章→附属图表。选择题 180 道，每题 4 个选项；七选五 60 空，每空关联共享的 7 个备选项。已有 5 套的语言运用与写作草稿保留，但本轮不扩展其题目。

迁移 drizzle/0014_reflective_cable.sql 已在本机应用。阅读导入使用主键 UPSERT，并在单个事务内写入。重复导入不会增加重复题目；不会覆盖 VERIFIED 答案。不要再次执行旧的初始语料构建来替换最终数据。
