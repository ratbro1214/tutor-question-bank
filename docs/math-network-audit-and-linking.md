# 全量资源与项目关联核验

核验日期：2026-10-19
项目入口：http://localhost:5173/knowledge-network

## 资源结果

- 全量收集页面、样式、脚本固定请求、正文/分片、预览、原件及教材索引中的文件路径。
- 2,702 个实际可用路径通过本地 HTTP 检查，均为 200；同时检查文件类型，防止把“200返回首页”误认成下载成功。
- 674 个预览资源的完整 SHA-256 均与来源记录一致。
- 补齐 272 份原件，完整 SHA-256 与来源记录一致；补齐的另外 10 个 PDF 均通过文件签名与路径哈希前缀核验，其中6个为来源PDF、4个为正文附带PDF。
- 修复核对说明页、相对链接与本地样式，补齐 EMF 原图；浏览器不支持的 EMF 改为原文件下载入口。
- 7 个原件地址和5张历史目录证据图实际上返回网站首页。伪文件移入当前聊天 work/math-network/unavailable-originals/，不作为正常资料提供。7份原件在界面明确标注不可用；5张图只保留在来源元数据中，原界面并不展示。
- 校正原站过时的“原件未发布”状态，但不修改原始来源哈希、引文或知识审核状态。

## 知识与题目关联

覆盖486个原站知识/主题节点：91个对应项目题目分类，21个对应唯一同名知识目录条目，两组有重叠，共98个有明确关联。388个未建立直接知识对应；保留逐项待核对清单，不通过模糊字符串或章节归属伪造知识等价。

当前用户可访问题库共73道，全部已扫描；58个原站节点有当前题目分类命中。此数字是原站节点数，不是去重题目数。

打开任意知识详解，顶部新增可展开的“本项目知识点与题目”：

- 直接展示同名或明确的分类包含关系，并保留匹配依据。
- 查询已有分类下的真实题目，可直接打开题目详情。
- 已审核目录挂载仅使用当前修订且已审核的关系；待审核目录条目继续标注待审核。
- 同章节拓展单独标识，不算当前知识点的直接题目匹配。
- 私有题目仍使用项目原有登录和题库权限，不写入公开JSON，不改动现有题目、审核状态或数据库结构。

项目文件：data/math-network/project-crosswalk.json、lib/math-network-mapping.ts、app/api/math-network/related/route.ts、public/math-network/project-related.js。
