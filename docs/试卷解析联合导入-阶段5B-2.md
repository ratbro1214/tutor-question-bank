# 5B-2 试卷与配套解析

2026-10-11 增量实现。详细审计、文件清单、迁移、API、验证证据、未验事项与手工步骤见 [验收报告](../../outputs/5B-2-验收报告.md)。

入口：原 `/papers` 增加可选解析 PDF；试卷详情“配套解析审核”进入 `/papers/:id/solutions`。先沿用原功能保存裁切题目，再切割解析、审核关联，按题触发基础核查或深度解法与通法。原始文件与提取文本保留，教师副本和 AI 输出分别保存。

新增 0018、0019 为增量迁移。本地迁移已执行且旧表内容哈希不变；云端未迁移。本地迁移工具只对当前项目停止运行时的 D1 文件操作，先 SQLite 备份再执行事务；复用脚本时提供核实后的本地数据库路径，见 `scripts/apply-paper-solutions-local.mjs`。

Windows 本地开发入口现已复用 E 盘安装的 MinerU 4.0：当 PDF 文字层未识别到明确题号时，切割按钮自动读取扫描正文的 OCR 行坐标，清理水印后按题号切割并保留跨页原图。本地插件不随云端构建提供 OCR 服务；复杂多栏版面仍需教师核查。原图优先展示，识别文字可展开，公式准确性不能仅靠 OCR 保证。

本地适配器使用已安装的模型，不在请求中安装工具或下载模型；版本不兼容会报错。同一来源重复请求复用识别任务，一次仅运行一个识别引擎；关闭开发服务会取消其识别子进程。中间文件保存在项目 `work/local-solution-ocr`。旧水印提取记录保留，未审核来源可增量修复；已有教师审核的来源拒绝覆盖。

AI 使用已有模型配置，质量核查与方法生成是两个可恢复的持久化阶段；未提供图像像素，不能核验图形或宣称数学证明已形式化验证。只有匹配和题目快照有效、教师接受、核查暂未发现明显错误的结果才进入备课上下文。真实扫描件的修复与验收见 [本地切割补充报告](../../outputs/5B-2-本地切割补充验收.md)。
