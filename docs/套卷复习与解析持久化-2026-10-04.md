# 套卷复习与解析持久化

## 使用

1. 从主导航进入“套卷复习”，上传 PDF、JPG 或 PNG。原文件独立保存，不需要绑定学生；默认高中。文件上限 40MB，PDF 最多 80 页。
2. 文字版 PDF 在浏览器用本地 PDF.js 读取题号和位置，生成裁切预览。支持左右双栏、大题题号、跨页和跨栏续题；小问、选项和小数不会作为新的题号。
3. 填写 `1,3,7-10,17` 选择指定题目，或全选。找不到的题号会明确提示。扫描件、文字层不完整的 PDF 可以使用当前视觉模型定位题号，也可以手动添加题目。
4. 检查原题、选项和图形是否完整。“调整裁切”支持拖动框选、输入百分比和添加跨页片段。按照片段顺序拼接，自动移除纯空白片段及多余上下空白；不根据文字层删除图形。
5. 点击“确认裁切并解析所选题目”，或仅保存题目。解析逐题处理、逐题写入数据库；失败不会回滚已完成题目。可停止并重新处理待完成题目，已有结果不会重复消耗模型调用。
6. 重新打开套卷可查看原文件、裁切题图、分类建议和解析。题目分类是 AI 建议；解析不会成为学生作答或学习记录。也不会修改现有智能体逻辑。
7. 需要修正已保存的裁切时，进入“继续选题 / 手动裁切”，调整对应题号后保存。修改裁切保留旧解析，并标明需要重新生成；新解析成功后替换。并发更新或正在解析时，拒绝过期裁切写入。

## 持久化

- 旧版单题“生成解析”只返回页面状态，必须另点保存。本次改为生成完成、校验通过后先写 `question_explanations`，再返回成功；未经教师核对的解析仍标记为待核对。
- 手工修改停止输入约 1.2 秒后自动保存完整内容，保存时禁用输入以避免旧响应覆盖正在输入的新内容。未完成编辑和保存失败的内容保存到浏览器本机草稿，按学生与题目分开；重新打开后恢复。
- 本机草稿不是服务器数据库的替代。跨页面版本不一致时停止自动保存，提示复制要保留的编辑，再读取服务器版本。
- `papers` 保存原文件信息和 SHA-256；`paper_questions` 保存题号、裁切片段、题图、识别文本、分类建议、解析、版本与任务状态。同一文件复用已有套卷，同卷同题号不重复插入。
- D1/R2 本地状态继续使用项目已有 `.wrangler/state`。原始 PDF、裁切题图、解析均随本地状态保留；不要删除此目录。它在 Git 中忽略，Git 提交不能替代数据库和对象存储备份。
- 本机迁移前已备份数据库。新增迁移 `0013_clumsy_cammi.sql` 只新增套卷表，不更改原有学生、题目和学习记录。其他已有环境先备份，再仅执行缺失迁移。

## 验证与边界

- `node --import tsx --test 'tests/*.test.ts'`：题号范围、双栏、跨页、答案页排除、解析转义、未完成草稿、数据库约束以及原有功能回归。
- `scripts/prepare-persistence-fixture.mjs` 创建独立的 D1/R2 运行目录，不复制真实模型密钥。`scripts/test-question-explanations.ts` 在 8790/8791 验证单题自动保存；`scripts/test-papers.ts` 验证文件复用、裁切保存、失败隔离、重试、旧解析保留、版本检查、停止任务和旧任务迟到结果拒绝。
- 浏览器用两页双栏合成 PDF 验证按题号选择 `1,4`、跨页题裁切、真实 DeepSeek 解析、失败单题重试及刷新读回。该合成样本不是各种实际试卷布局的全面评测。
- 自动裁切需要人工核对。异常排版、题号识别遗漏、参考答案与题目混排或图形超出栏宽时，使用手动调整；扫描版 AI 定位可能不精确。
- 每个完成的题目都保存。页面关闭后不会继续启动队列中未开始的题；重新打开可继续解析。异常断开留下的 processing 状态，最多在 8 分钟租期后允许重试；正常点“停止”会主动释放当前任务并拒绝迟到结果。
- AI 模型的结构与公式排版校验不等于数学正确性核验。格式不齐会在共享的 5 分钟上限内自动重试一次，仍失败则保留已有解析。
# 套卷与个人题库联动

套卷详情的已保存题目区新增“加入个人题库”。勾选题目，选择个人或学生档案，核对原图和分类后批量添加。需要先完成分类解析；新增题目包含独立原图、分类、知识点和已有解析，解析仍标记为未核对的 AI 内容。可在仪表盘创建自己的复习档案。

同一套卷题目在同一档案中只添加一次，重复操作返回已有题目，不覆盖个人修改；已移入回收站的题目需要先恢复。个人题目详情保留套卷来源链接。此操作不创建提问、作答或掌握情况记录；套卷后续重新解析也不自动覆盖个人内容。

接口：`POST /api/papers/:id/archive`。复用唯一 `submission_id` 保存来源映射，无需新增数据库迁移。隔离环境联动验证：`node --import tsx scripts/test-paper-archive.ts`，仅允许访问 `127.0.0.1:8790`。
