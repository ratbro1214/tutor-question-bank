# 初高中公共数学资料包

资料已本地保存，应用运行时不请求 GitHub。首次打开数学知识图谱或解题方法库默认显示公共资料；“我的题库与教师维护”保留原有私有题库、审核、版本历史与真实解析关联。

## 内容与来源

- 161 个初高中知识点、176 条先修建议：`xmonkey/mathmap-cn`，版本 `74f05d421c8d72de68d983dbdef160e55c0873e8`。
- 32 张高中方法卡：根据 `liuhaopeng543/MathBook` 的集合、不等式、函数、三角函数、向量、解析几何、数列、导数、概率和组合计数等章节整理，版本 `5b81b2d8cd2fc0fb5c6dee5e8c064f4416582aaf`。
- 12 张初中方法卡：根据 mathmap-cn 的知识点及学习目标，由本项目补充流程、条件、局限与易错点。
- 获取日期：2026-10-11。`manifest.json` 保存各原始文件的 SHA-256 与大小；`sources/` 保留原文件，`catalog.json` 是应用消费的结构化资料。

这不是权威课标数据库。mathmap-cn 明确说明其教学描述与关系是 AI 教学常识初稿，需要教研核查。方法卡是项目整理、补充的教学参考，不宣称逐字摘自上游、不宣称教师已审核。公共资料可直接浏览，但复制到私有方法库一律先存为 candidate；不自动建立真实题目解法关系。

## 处理范围

仅纳入上游 stage4（初中）与 stage5（高中）知识点，保留直接关联。省略 28 条涉及资料包以外知识点的原始关系记录，并对重复关系去重。因此当前图谱没有显示某个前置，不表示它不需要小学基础。章节分组由本项目按知识点标识整理，不修改原始快照。

MathBook 包含拓展知识、外部图片及例题；原 Markdown 只作为来源快照保存。应用展示经整理的通用方法，不下载外部图片、不把上游例题冒充真实题库内容。原始笔记存在条件省略及可能的计算错误，不应不经核查整体当作可信答案库。

## 可复现更新

1. `scripts/fetch-open-math.ps1`（Windows）或 `scripts/fetch-open-math.mjs`（Node 网络环境）只下载明确列出的固定版本文本与 JSON。
2. `scripts/build-open-math.mjs` 先检查快照哈希，再生成 catalog。编辑整理内容可修改两个 `method-seeds.mjs` 文件后重新生成。
3. 对新上游版本先检查许可、质量与数据差异，再更新固定版本；运行 `tests/open-math.test.ts`。

公共资料只读显示，不迁移或覆盖活动数据库。
